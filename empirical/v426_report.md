# v4.26 报告 · 移除成长因子噪声（g=0）

## 一、结论（一句话）
把 lvrev 内核里**成长（营收增速）因子的权重从 0.08 清零**，v4.25 基线 **+10.14% / 夏普 0.19** → v4.26 **+28.59% / 夏普 0.40**，回撤 21.8%→21.1%，所有指标同向改善。这是一次**极简、数据支撑、隔离验证**的改动，非参数调优。

## 二、为什么要清零成长
- `#23` 实证截面 Rank-IC：成长（营收增速）fwd60 IC = **−0.030（t=−1.62，弱负且不显著）** —— 对收益既无正贡献、还引入噪声。
- 因子已排序为 rank-pct 用于打分；给一个弱负因子 0.08 权重 = 让"高增速"票在 composite 里被虚高，部分弱票借成长分爬过 `MIN_PICK_SCORE=0.80` 闸门。
- 清零后闸门自动收紧（composite 上限从 1.0→0.92），**选中票质量提升**：笔数 364→299、净胜率 45.9%→45.5%、盈亏比 1.30→1.47。

## 三、方法论（沿用 v4.25 隔离协议 + 用户授权并行加速）
1. 在 `local_backtest.py` 新增 `--vol-weight/--rev-weight/--q-weight/--g-weight` CLI 覆写（monkeypatch `W_DEFAULT`/`W_VALUE`），使**多个候选变体对同一份源码并行跑**（不同 CLI 参数，无逐变体改文件冲突）。
2. 用户授权提高 CPU/内存占用加速 → **6 个变体全并行后台启动**（同份源码、各自独立日志）。

## 五、关键洞察（重申 v4.25 教训）
- **极简改动最优**：只清零一个弱负因子，收益近乎翻倍、夏普翻倍。任何"权重倾斜"（向低波/向反转增减）都画蛇添足 —— Wvol50 甚至崩到 −4.03%。因子改动存在**非线性交互**，改动越多越危险。
- 低波（IC+0.127，强正）是当前唯一应重仓的真实 alpha；反转（IC+0.065，弱正）次之；成长（IC−0.030）应彻底退出打分。
