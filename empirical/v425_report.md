# v4.25 实证报告：砍掉 ROE 正向排序 → 总收益 +0.59% → +10.14%

> 日期 2026-08-21/22 ｜ 解释器 `D:\env\python3.12`（pandas 3.0.5）｜ harness `local_backtest.py` 默认参数（mh30 / 含成本 / 含 T+N / 资本无关）｜ 数据 2020-01-02~2026-08-21（market.db）

## 一句话结论
圆桌"砍 ROE 权重"的直觉方向对，但**实现方式错**：原补丁把「W_DEFAULT 重加权(A)」与「去 ROE 排序(B)」捆绑，触发灾难性非线性交互（−5.51%）。隔离 ablation 证明 **B 单独是真正赢家（+10.14%）**，A 小幅改善（+0.93%）却与 B 互斥。v4.25 = **只落地 B**，W_DEFAULT 保持原值（q=0.12，**绝不可同降到 0.05**），不加 multifactor 闸门。

## 根因（为什么 B 赢、A+B 崩）
1. **ROE 是负 alpha，但引擎里它是「正向排序偏置」而非纯多空**：#23 实测 ROE 截面 Rank-IC = −0.078（t=−2.94，显著负），即高 ROE 股票未来相对跑输。原内核 `s_q += d["roe"].clip(-20,40)/40` 给高 ROE 股打了质量分加成 → 系统性选中跑输股。移除该项（B）即消除该偏置，避开一大批未来走弱标的 → **+10.14%**。
2. **A 与 B 的非线性交互是陷阱**：A 把 q 权重从 0.12 砍到 0.05，把权重让给 vol/rev。单独用（保留 ROE）只微调（+0.93%）。但一旦同时移除 ROE（B），质量项只剩 debt_ratio（防御信号），此时再把 q 砍到 0.05、过度放大低波/反转，组合被推向极端集中区，方向 alpha 失效 → 崩到 −5.51%。**两因子对 q 权重的敏感度在「无 ROE」状态下被放大数倍**。
3. **multactor 估值/质量硬闸门（C/D）对回测零影响**：回测直接 `from lvrev_scorer import score_lvrev`，不调用 `multifactor._score_l4_lvrev`，故 C/D 不参与回测 P&L（它们只影响每日管线候选过滤，效果未在此验证，故不纳入 v4.25）。

## 落地内容（v4.25 commit）
- `src/lvrev_scorer.py`：质量分 `s_q` 移除 ROE 正向排序项，仅保留 `debt_ratio` 低杠杆稳定器。`W_DEFAULT` **未改动**（q 仍为 0.12）。
- 其余文件（config.yaml / multifactor.py）保持 v4.24，未加 C/D 闸门。
- 证据与工具入库：`empirical/ablation.py`、`empirical/logs/bt_ablation_A.log`、`bt_ablation_B.log`、`bt_v424_unpatched_sameinterp.log`、`bt_v425_patched.log`、`bt_v425_final_confirm.log`。
- 原组合补丁 `empirical/apply_v425_patch.py`（A+B+C+D）保留但标 `REJECTED`，仅供复盘。

## ⚠️ 诚信与风险提醒（上线前必读）
- **+10.14% 是 2020-2026 单样本内结果**（年化 +1.58%），非样本外验证。因子/权重在 in-sample 上可能过拟合。
- **上线实盘前建议做 walk-forward 样本外确认**（滚动窗口训练/测试），尤其验证 2022 熊市 −11.6% 是否可控。
- 用户为**散户实盘、无杠杆/无对冲**，即便 v4.25 改善，仍须保守仓位（单只≤8%、 sleeve 上限、L0 闸门空仓时停泊逆回购），不可因回测改善而加杠杆。
- 后续可验证的圆桌其他杠杆（未被证伪）：L1 行业轮动闸门 / L0 择时精细化 / 逆向 ETF 恐慌榜 / PEAD / ≤15% 短线袖珍仓 —— 须逐一 ablation + OOS 后再落地。

## 关键教训（固化）
> **截面 Rank-IC 为负 ≠ 组合实盘改善；但「移除负 IC 因子的正向排序偏置」在本引擎确实有效。**
> 改内核权重/因子必须走**隔离 ablation + walk-forward**，绝不凭 IC 符号拍脑袋捆绑多改动——多因子引擎存在强交互，组合效果不可线性外推。
